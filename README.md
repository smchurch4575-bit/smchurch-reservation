# 이음센터 활동실 예약

교회 활동실 예약 웹 화면입니다. 화면은 **GitHub Pages**에서 열고, 예약 내용은 **구글 시트**에 저장됩니다.

- 예약 / 내 예약·취소 / 주중 시간표 / 주일 시간표
- 겹치는 시간은 서버가 막습니다 (동시에 눌러도 한 명만 예약됨)
- 취소: 예약한 본인(연락처 확인)과 관리자만 가능
- 연락처는 공개 목록에 나오지 않습니다 (관리자 로그인 때만 보임)

```
index.html          화면
config.js           ← 서버 주소를 넣는 파일 (설치 3단계에서 수정)
apps-script/Code.gs 구글 시트 서버 코드
test/               시험 코드 (몰라도 됩니다)
```

## 설치 (처음 한 번, 약 10분)

### 1. 구글 시트 만들기
1. [sheets.new](https://sheets.new) 로 새 시트를 만듭니다. 이름은 자유 (예: `이음센터 예약`).
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.

### 2. 서버 코드 넣기
1. 편집기에 있는 기본 코드를 모두 지우고, 이 저장소의 `apps-script/Code.gs` 내용을 통째로 붙여 넣습니다.
2. 왼쪽 톱니바퀴(**프로젝트 설정**)에서 **"appsscript.json 매니페스트 파일 편집기에 표시"** 를 켜고, 파일 목록의 `appsscript.json` 내용을 이 저장소의 `apps-script/appsscript.json` 내용으로 바꿉니다. (시간대가 한국 시간이 됩니다)
3. 같은 **프로젝트 설정** 맨 아래 **스크립트 속성 → 속성 추가**
   - 속성: `ADMIN_PIN`
   - 값: 관리자 비밀번호 (직접 정하세요. 추측하기 쉬운 숫자는 피하세요)
4. 저장(디스크 아이콘).

### 3. 웹 앱으로 배포하고 주소 복사
1. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
2. 설정
   - 설명: `예약 서버`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
3. **배포** → 권한 승인 창이 뜨면 구글 계정을 고르고 **고급 → (프로젝트 이름)(안전하지 않음)으로 이동 → 허용**
   (본인이 만든 코드라서 나오는 경고입니다.)
4. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사합니다.
5. 이 저장소의 `config.js` 에서 `apiUrl: ''` 의 따옴표 안에 그 주소를 붙여 넣고 저장(커밋)합니다.

### 4. GitHub Pages 켜기
저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**
1~2분 뒤 `https://<계정>.github.io/<저장소>/` 주소로 열립니다.

## 사용법
- **예약**: "예약하기" → 장소·교구·셀·날짜·시간·성함·연락처 입력 → 예약 확정
- **내 예약/취소**: 성함과 연락처를 넣고 조회 → "예약 취소". 같은 기기에서 예약했다면 바로 보입니다.
- **관리자**: "내 예약/취소" 아래 **관리자**를 열어 비밀번호로 로그인 → 모든 예약·연락처 확인, 아무 예약이나 취소, 엑셀용 파일 받기

예약 내역은 구글 시트의 `예약` 탭에 쌓입니다 (취소된 예약은 "취소"로 표시되어 기록이 남습니다).

## 꼭 알아 둘 점
- **시트를 남에게 공유하지 마세요.** 시트에는 연락처가 그대로 저장됩니다. 서버(Apps Script)는 시트 주인 계정으로 실행되므로, 공유하지 않아도 예약은 정상 동작합니다.
- 화면 주소를 아는 사람은 누구나 예약 목록(이름, 교구·셀)을 볼 수 있습니다. 연락처는 보이지 않습니다.
- 취소할 때의 본인 확인은 "예약할 때 입력한 연락처"입니다. 연락처를 잘못 입력했다면 관리자가 취소해야 합니다.
- 정기 셀모임 시간 막기는 화면(`index.html`)에서만 합니다. 시간이나 장소가 바뀌면 `index.html` 안의 `WEEKDAY`, `SUNDAY` 표를 고치세요.
- 서버 코드(`Code.gs`)를 고쳤다면 **배포 → 배포 관리 → 편집(연필) → 새 버전 → 배포**를 해야 반영됩니다. 주소는 그대로 유지됩니다.
- 목록은 20초마다 자동으로 새로 고쳐집니다.
- 구글 Apps Script는 하루 사용량 한도가 있습니다. 교회 한 곳이 쓰는 정도에서는 충분할 것으로 보지만, 확실하지 않음.
